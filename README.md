# IBM Automation Architecture MVP

A first working React Flow and IBM Carbon prototype demonstrating:

- Product Mode
- Concert Platform Mode
- Clickable interface edges
- Better Together detail panels
- Animated, step-driven journeys
- Human approval indicators
- Reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## MVP journeys

- Terraform + Ansible
- Instana + Turbonomic
- Concert alert to resolution

## GitHub Pages

The Vite base is relative (`./`). Build with `npm run build`, then publish the generated `dist` directory through your preferred GitHub Pages workflow.

## Content note

The Concert alert-to-resolution sample includes preview-oriented content and is labelled accordingly in the model. Review public-release status before external publication.
